2. 프로젝트 만들기	
================================================================
	
	----------
	1)	절차..
	----------

		1.	작업 폴더에 대화상자 기반 프로젝트 생성..
			
			-	이름..
				ㄴ	"SimpleCalculator"


		2.	리소스에 에디터 3개와 버튼 1개를 생성..

			1)	[ 리소스 뷰 ]
				> [ 대화 상자 ] 선택..

			2)	도구상자..
				>	[ Button ] / [ Edit Control ] 선택..
				>	[ 대화상자 ]위에 적당한
					위치에 클릭..
				>	드래그하여 위치 및 크기 정리..

			3)	각 컨트롤 들의
				아이디 및 기타 속성 설정..
						
				===========================================================
				컨트롤				|	ID						|	Caption
				===========================================================
				[ Edit Control ]	|	[ IDC_EDIT_NUMBER1 ]	|
				[ Edit Control ]	|	[ IDC_EDIT_NUMBER2 ]	|
				[ Button ]			|	[ IDC_BUTTON_SUM ]		|	더하기
				[ Edit Control ]	|	[ IDC_EDIT_RESULT ]		|
				===========================================================
			
			4)	에디트 컨트롤과
				연계하는 변수를 추가..

				1)	에디트 컨트롤
					>	마우스 우클릭..
					>	팝업..
					>	[ 변수 추가 ] 선택..
				

				2)	범주		:	[ 값 ]
					이름		:	[ _num1 ] / [ _num2 ] / [ _result ]
					변수 형식	:	[ int ]


				3)	[ SimpleCalculatorDlg.h ]에
					해당 데이터 추가된 것 확인..


			5)	버튼 이벤트 등록..

				1)	[ 버튼 컨트롤 ]
					>	[ 마우스 우클릭 ]
					>	[ 팝업 ]
					>	[ 이벤트 처리기 추가 ] 선택..

				2)	클래스 목록..
					ㄴ	[ CSimpleCalculatorDlg ]

				3)	메세지 형식..
					ㄴ	[ BN_CLICKED ]

				4)	함수 이름..
					ㄴ	[ OnBnClickedButtonAdd ] 또는
						편집해서 사용..


			6)	OnBnClickedButtonAdd 구현..
				
				void CSCDlg::OnBnClickedButtonAdd()
				{
					UpdateData(TRUE);
					_result = _num1 + _num2;
					UpdateData(FALSE);
				}
				
				* BOOL UpdateData( BOOL bSaveAndValidata = TRUE )
					
					-	bSaveAndValidata..
						-	데이터의 이동 방향..
						-	TRUE	: 복사 from [ 대화상자 ] to [ 멤버 변수 ]..
							FALSE	: 복사 from [ 멤버 변수 ] to [ 대화상자 ]..

1.	대화 상자 기반 프로그램 만들기..
	[ 참고 :	https://blog.naver.com/tipsware/221306344658 ]
================================================================

	----------
	1)	정의..
	----------

		-	응용 프로그램과 사용자 사이의
			의사소통을 하는 통로..

			ㄴ	인터페이스..
		
			예) [ 윈도우 + R ]을 통해 실행되는 실행창..

				메뉴에서 나오는 파일 열기 및 저장 창 등..


	----------
	2)	절차..
	----------

		----------------------------
		1.	탭 > 애플리케이션 종류..
		----------------------------

			-	응용 프로그램 종류 > 대화상자 기반..
			-	탭 문서, 문서/뷰 아키텍처 지원 off..
			-	나머지는 기본 옵션..



		---------------------------
		2.	탭 > 문서 템플릿 속성..
		---------------------------

			-	SDI / MIDI에서는 사용하지만
				대화상자 기반에서는 사용하지 않음..
				ㄴ	다음 절차 진행..

				

		---------------------------------
		3.	탭 > 사용자 인터페이스 기능..
		---------------------------------

			-	대화상자의 외형( 스타일 ) 설정단계..
			-	시스템 메뉴를 제외한 나머지 off..




		--------------------
		4.	탭 > 고급 기능..
		--------------------

			-	[ 공용 컨트롤 매니페스트 ]를 제외한
				나머지 off..

				-	Windows XP 및 새 운영 체제에 포함된
					공용 컨트롤 DLL을 사용할 수 있도록 하는
					애플리케이션 매니페스트를 생성..

				-	매니페스트 파일..
					-	패키지에 포함된 파일을 열거해놓은
						컴퓨터 파일..



		------------------------
		5.	탭 > 생성된 클래스..
		------------------------

			-	선택한 [ 응용 프로그램 형식 ]에 따라 추가되는
				클래스의 이름이나 파일을 보여줌..
			-	[ 대화 상자 기반 ] 프로그램이므로 
				[ 생성된 클래스 ]를 [ Dlg ]로 구분해 줌..

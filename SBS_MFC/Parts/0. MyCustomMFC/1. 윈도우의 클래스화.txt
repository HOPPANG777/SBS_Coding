1. MFC, 윈도우의 클래스화..

	----------
	1.	정의..
	----------

		---------
		-	MFC..
		---------

			-	Microsoft Foundation Class..

			-	[ WinAPI ]를 사용하기 쉽게 하기위해
				[ 클래스화 ] 시킨 것..

			-	[ WinAPI ]가 [ C 기반 ]이라면
				[ MFC ]는 [ C++ ] 기반임..

			-	최근에 사용되는 대부분의 게임 엔진들이
				MFC와 유사한 방식으로 가동됨..
	


	----------------------
	2>	WinAPI의 클래스화..
	----------------------

		---------------------
		-	WinAPI 분석하기..
		---------------------

			===============================================================
							|	주요 기능..			|	주요 속성..
			===============================================================
				WinMain..	|	윈도우 클래스 등록..	|	WNDCLASS..
							|	( WNDCLASS )		|
							|						|	
							|	윈도우 생성..		|	HWND, 인스턴스 값,
							|						|	클래스 이름,
							|	메시지 루프..		|	윈도우 이름 등..
							|						|	
							|	종료 처리..			|	
			===============================================================
				WndProc..	|	메시지 처리..		|	윈도우 핸들, 메시지,
							|						|	부가정보..
							|						|	( WPARAM, LPARAM )
							|	각 메시지에 대한 		|	
							|	이벤트 처리..		|
							-----------------------------------------------
							|	기타 메시지 처리..	|
							-----------------------------------------------
							|	종료 처리..			|	
			===============================================================



		------------------
		-	클래스화 하기..
		------------------

			------------
			1)	캡슐화..
			------------

				-	기능 -> 멤버 함수..
				
				-	속성 -> 멤버 변수..


			------------------
			2)	클래스 멤버를
				설계할 때 팁..
			------------------

				-	[ 기능 ]을 중심으로
					[ 속성 ]을 설계할 것..

					-	해당 클래스가 시스템 내부에서
						어떤 식으로 [ 동작 ]할 것인지 고민..
						
						-	[ 기능 ]을 먼저
							설계할 것..
						
						-	책임 또는 역할을 담당하게할 것..
							ㄴ	멤버 함수..

					-	해당 역할 또는 책임에 필요한 데이터가
						계속 유지 되어야 한다면 클래스의
						[ 속성 ]으로 추가..

						ㄴ	멤버 변수..



						예)	사과 상자라는 클래스

							-	주요 기능..

								1)	사과를 담는다..
								2)	사과를 카운팅 한다..
								3)	이동 한다..
									.....


							-	주요 속성..

								-	사과 배열..
								-	사과의 갯수를 관리할 변수..
								-	좌표 정보, 속도 값..
									.....	



			------------------------
			3)	멤버 함수 설정시 팁..
			------------------------

				1)	매개 변수로 설정하려는 요소들 중

					1)	기존 멤버 변수와 중복..

					2)	기존 멤버 변수의 데이터와
						중복된 데이터 인 경우...
						
						-	매개 변수에서 제외,
							함수 내부에서 멤버 변수로
							대체하는 것을 고려할 것..

					

				2)	일부 멤버 함수들이

					1) 항상 동시에 호출..

					2) 항상 같은 순서로 호출 되는 경우..

					-	하나의 멤버 함수로 만들 것..

						ㄴ	래핑 함수( Wrapping )..

						예)	Do_A();
							Do_B();
							Do_C();

							--->	Do_D()
									{
										Do_A();
										Do_B();
										Do_C();
									}


			------------------------
			4)	멤버 변수 설정시 팁..
			------------------------

				-	모든 속성을 멤버 변수로
					만들 필요는 없다..

					-	사용할 때마다 초기화한 상태에서
						갱신되는 속성이라면
						외부에서 매개 변수로
						전달받는 것도 고려..




	Q ) [ 3. WinApi\_ 강의 소스\1. First Exam\FirstExample ]를 이용하여
		윈도우를 생성하고 메시지를 처리하는 클래스를 만듭니다..

		메시지는 [ WM_PAINT ], [ WM_DESTROY ], [ WM_LBUTTONDOWN ]으로 하고
		다음과 같이 처리합니다..

		WM_PAINT..
		ㄴ	간단한 텍스트나 이미지 그리기..

		WM_LBUTTONDOWN..
		ㄴ	왼쪽 마우스 버튼 클릭시 메시지박스로 알림..

		WM_DESTROY..
		ㄴ	프로그램 종료시 메시지박스로 알림..

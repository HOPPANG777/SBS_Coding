====================================================
1.  Win API ( Windows Application Interface ) 소개..
====================================================

    --------------------
    -   윈도우즈의 특징..
    --------------------

        -   공통 GUI를 가짐..
               ( Graphic User Interface )

            ㄴ   버튼, 체크박스, 에디터,
                 메뉴 등등..

        -   FIFO 방식( Queue )의
            메시지 처리 방식..


        -   멀티 태스킹, 멀티 스레딩 방식 지원..

            ====================================================================
                            |   공통점..  |   작업 주체..      |   작업 대상..
            ====================================================================
            멀티 태스킹..    |            |   운영체제         |   여러 개의    
                            |  동시에    |                    |   응용프로그램..
                            |            |                   |   ( Application )
            -----------------  실행..    --------------------------------------
            멀티 스레딩..    |            |   응용프로그램     |   여러 개의
                            |            |                   |   실행 흐름..
                            |            |                   |   ( 스레드 )
            ====================================================================


    --------------------------------
    @   윈도우즈 응용프로그램의 특징..
    --------------------------------

        ---------------------
        1)  API 호출문 집합..
        ---------------------

            -   윈도우 API..
                ( Application Programming Interface )

                -   윈도우즈 운영체제가
                    응용 프로그램을 위해
                    제공하는 각종 함수의 집합..

                -   Win16 API, Win32 API,
                    Win64 API..


        ------------------------
        2)  메시지 핸들러 집합..
        ------------------------

            -   메시지 핸들러..
                ( Message Handler )

                ㄴ   메시지를 받았을 때
                     동작을 결정하는 코드..

                ㄴ   윈도우 프로시져
                     ( Window Procedure )
                    
                     ㄴ   메시지 핸들러 집합..


        --------------
        3)  실행 파일과
            Dll 집합..
        --------------

            -   Dll..
                ( Dynamic Linked Library )
                [ 참고 : https://saack.tistory.com/31 ]

                ㄴ   프로그램이 실행중에
                     결합하여 사용 가능한
                     코드와 리소스 집합..


            -   윈도우 API는 Dll 형태로
                제공되며, 개발자는 필요시
                Dll을 만들어 사용 가능..


    ------------------------
    -   Win Api의 기본 골격..
    ------------------------

        1)  윈도우 클래스 정의..

        2)  1)을 운영 체제에 등록..

        3)  윈도우 생성 및
            화면에 표시..

        4)  메시지 루프 구동..

        5)  윈도우 프로시져 처리..



    ---------------------------
    @   Window Api 샘플 분석.
    ---------------------------
    
        ------------------------
        -   샘플 프로젝트 만들기..
        ------------------------
        
            1)  비주얼 스튜디오 실행..

            2)  새 프로젝트 만들기..

            3)  C++ / Windows / 데스크톱 선택..

            4)  Windows 데스크톱 애플리케이션..

            5)  프로젝트 생성 경로 및 이름 설정.


        -----------------------
        -   빈 프로젝트 만들기..
        ------------------------

            1)  비주얼 스튜디오 실행..


            2)  새 프로젝트 만들기..


            3)  C++ / Windows / 데스크톱 선택..


            4)  Windows 데스크톱 마법사..


            5)  프로젝트 생성 경로 및
                이름 설정..


            6)  애플리케이션 종류..

                ㄴ   데스크톱 애플리케이션 선택..

                추가 옵션..

                ㄴ   빈 프로젝트 선택..


            7)  예제 소스를 위한
                프로젝트 설정..

                ㄴ   구성 속성 / 고급 / 문자 집합..

                    ㄴ   멀티바이트 문자 집합..

=================================================================================
	IPC
=================================================================================

	---------
	-	IPC..
	---------

		-	각 프로세스들은
			메모리와 CPU를 공유할 뿐
			서로 독립된 일을 하며
			상호 간섭하지 않고
			간섭할 수도 없음..
	
		-	필요에 따라
			프로세스간에 정보를
			교환해야할 경우가 생기는데
			이때 정보를 교환하는 방법을
			IPC라고 함..
			( InterProcess Communication )
	
		-	메시지, 클립보드, 파일 맵핑,
			윈속, 원격함수 호출(RPC) 등의
			방법이 있음..


		-	방법..

			방법 1)	메시지 방식..
					참고 : [ IPCMessage ]

				-	가장 간단하고 빠름..

				-	두 프로세스가
					서로의 윈도우 핸들만
					알고 있다면
					wParam과 lParam을 통해
					정보 교환 가능..

				-	메모리를 거치지 않고
					운영체제에 의해
					직접 전달..

				-	비교적 크기가 작은
					정보를 전달할 때 사용..
					-	문자열이나 크기가 큰 구조체는
						전달 불가능..
					-	wParam, lParam은
						둘다 4바이트에 불과함..
		
				

			방법 2)	IPC 전용 메시지 방식..
					참고 : [ CopyData ]

				-	[ WM_COPYDATA ] 메시지 활용..
			

				-	wParam
					-	대상 윈도우의 핸들..
					lParam
					-	COPYDATASTRUCT의 포인터..

					struct tagCOPYDATASTRUCT
					{
						//	교환하고자 하는 정수값..
						ULONG_PTR dwData;

						//	lpData의 크기..
						DWORD     cbData;

						//	교환하고자 하는
						//	문자열(또는 이진 데이터)..
						//	포인터이므로
						//	구조체나 배열도 가능..
						PVOID     lpData;
					} COPYDATASTRUCT
	

				-	주의 사항..
					-	통신하는 양쪽이
						데이터의 포맷을
						알고 있어야 함..

					-	받은 쪽에서
						데이터를 다 사용하기 전에
						전달된 값이
						바뀌지 않도록 해야함..
						-	멀티스레드를 사용할 경우
							다른 스레드에서
							값을 변경할 가능성을
							차단 해야함..

	---------------------
	1.	윈도우즈를 구성하는
		주요 DLL..
	---------------------

		[ KERNEL ]

		-	메모리를 관리하고
			프로그램 실행..


		[ USER ]

		-	유저 인터페이스와
			윈도우를 관리..


		[ GDI ]

		-	화면 처리와
			그래픽 출력..


	----------------------
	2.	DC의 정의..
		( Device Context )
	----------------------
	
		-	[ Context ]
			[ 참고 : https://en.dict.naver.com/#/entry/enko/4d695b1e2850445a9be109b7482c50ae ]
				
			-	프로그램이 메모리에 올라갔을 때,
				실행되기위해 필수로 필요한
				메모리영역, 레지스터 값 등의
				리소스들을 총칭..

			-	어떤 루틴이 실행될 때
				변수값들, 이전에 실행된
				함수 들의 내부 상태 등..
				[ 참고 : https://kldp.org/node/51223 ]


		-	윈도 운영 체제에서 폰트,
			색상, 굵기, 무늬, 출력 방법 등
			화면 출력에 필요한 모든 정보를 가지는
			데이터 구조체..

		-	[ GDI ] 모듈에 의해 관리..

		-	출력에 필요한 모든 정보를
			가지는 데이터 구조체..

			ㄴ	디스플레이 DC( 화면출력 담당 ),
				프린터 DC( 프린터 출력 담당 ),
				메모리 DC( 비트맵 출력 담당 ) 등..

		-	폰트, 선의 색 / 굵기,
			그리기 모드 등을 관리..


	----------------
	3.	DC의 필요성..
	----------------

		1)	출력에 필요한 다양한
			정보의 통합 관리..

			예) Line( startX, startY, endX, endY, Color, Width, Shape, DrawMode, .....)
									
									vs

				Line(hdc, startX, startY, endX, endY)


		2)	출력 함수들이 참조하는
			원점 정보..

			예) (10, 10) ~ (40, 40) 으로
				선을 그릴 때 기준점은 어디인가?


		3)	윈도우끼리의 출력 결과가
			서로를 방해하지 않도록 완충 역할..

			예) 윈도우가 일부 겹쳐있을때
				어떤 영역이 출력 허가된 영역인가?


		결론)	DC의 역할..

				-	그리기에 필요한
					여러가지 정보 관리..

				-	안전장치 역할..

				->	모든 출력 함수는
					DC의 핸들을 공통으로 관리..

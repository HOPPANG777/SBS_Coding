	컨트롤

	------------
	1.	정의
	------------
		-	사용자로부터
			명령을 받아
			출력결과를
			보여주는 도구..
			-	[ UI ]
		-	버튼류, 에디트 박스,
			리스트 박스 등등...
		-	윈도우의 일종..
			-	[ CreateWindow ]로 생성..
		-	윈도우 클래스를 만들어
			( WNDCLASS )
			사용할 필요는 없음..
			-	윈도우즈가
				운영체제 차원에서
				미리 정의되어 있는
				윈도우 클래스를
				제공해주기 때문..

		-	컨트롤용
			윈도우 클래스 종류..
				================================
				윈도우 클래스	|	기능..
				================================
				button			|	버튼
				edit			|	에디트 박스
				listbox			|	리스트 박스
				combobox		|	콤보 박스
				scrollbar		|	스크롤
				static			|	스태틱
				================================

		-	[ WS_CHILD | WS_VISIBLE ]은 기본..

		-	[ 컨트롤의 3요소 ]

				1)	컨트롤 생성시 
					적용할 스타일..
				2)	컨트롤 -> 부모 ( 통지 메시지 )
				3) 	부모 -> 컨트롤 ( SendMessage )
		



	------------
	11.	과제
	------------

		리스트박스		-	도형 선택( 선/ 사각형/ 타원 )
		콤보 박스		-	도구 선택( 펜/ 브러시 )
		스크롤_1		-	R/ G/ B
		에디트_1		-	R/ G/ B 수치값.
		스태틱			-	각 컨트롤의 기능 명시.
		클라이언트 영역	-	도형 출력

		참고 사항)
			1.	각 컨트롤 기능과 도형 출력 기능을
				클래스로 만들 것..
			2.	팩토리 패턴으로
				컨트롤과 도형을 생성할 것..
			3.	각 클래스는
				헤더와 cpp로 구분할 것..

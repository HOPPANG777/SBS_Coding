	1.	용어 정리..
		[ 참고 : [0] Vertex_Polygon_Edge_Mesh.png ]
	---------------
	
		--------------
		1.	정점..
			( Vertex )
		--------------

			-	3D 공간상의 위치를 나타내는 점..

			-	폴리곤을 구성하는 기본 단위..

			-	좌표 정보외에 부가적인
				정보들도 포함 가능..

				-	위치, 색, 노멀,
					텍스쳐 좌표 등...


		---------------
		2.	폴리곤..
			( Polygon )
		---------------

			-	3개의 정점이 모여 만드는
				하나의 면( face )..

			-	최소한의 정점으로 만들수 있는 면..

			-	폴리곤이나 정점의 갯수가 많을수록
				메모리 양은 증가하지만
				더 디테일한 표현이 가능..
		
		
		------------
		3.	변..
			( Edge )
		------------

			-	정점과 정점을 연결하는 직선..

			-	변을 이용한 작업은 거의 없음..


		------------
		4.	메시..
			( Mesh )
		------------

			-	폴리곤들이 모여서 하나의
				3차원 물체를 만든 것..


		---------------
		5.	셰이딩..
			( Shading )
			[ 참고 : https://mm5-gnap.tistory.com/277
					 https://blog.naver.com/milulove/220728992684
					 [ 조명과 벡터의 연산( 내적 ).png ] ]
		---------------
			
			-	폴리곤에 음영을 넣는 작업..

			-	일반적으로 플랫( Flat ) 셰이딩,
				고라우드( Gouraud ) 셰이딩,
				퐁( Phong ) 셰이딩 등이 있음..


			==========================================================================
			기법..			|	특징..							|	구현 방법..
			==========================================================================
			플랫 셰이딩..	|	가장 기본적인 셰이딩..			|	면의 법선 벡터와 
							|-----------------------------------|	조명의 방향 벡터로
							|	폴리곤의 노벌 벡터와				|	면의 밝기 계산..
							|	조명의 방향을 내적하여			|
							|	연출..							|
			--------------------------------------------------------------------------
			고라우드			|	조명이 비춰지는 면들의			|	정점의 법선 벡터와 
			셰이딩..			|	평균적인 명암을 계산하여			|	조명의 방향 벡터로
							|	적용..							|	면의 밝기 계산..
							|-----------------------------------|
							|	인접면 사이의 경계가				|
							|	부드러움..						|
			--------------------------------------------------------------------------
			퐁 셰이딩..		|	고라우드 셰이딩과 유사..			|	픽셀의 법선 벡터와 
							|-----------------------------------|	조명의 방향 벡터로
							|	하이라이트나 반사광				|	면의 밝기 계산..
							|	표현 가능..						|
			==========================================================================


		-----------------
		6.	렌더링
			파이프 라인..
		-----------------

			-	3D 공간상의 오브젝트들을
				2D로 구성된 모니터 화면에
				표현하는 과정..


			-	과정..

				-	로컬 좌표계		->	월드 좌표계	->	카메라 좌표계	
				->	백스페이스 컬링	->	조명연산		->	클리핑
				->	투영				->	뷰포트		->	래스터 라이즈..

			---------------
			-	추가 설명..
			---------------

				-----------------
				-	로컬 좌표계..
					[ 참고 : [1] Local coord.png ]
				-----------------

					-	https://blog.naver.com/pok_jadan/188845751

					-	모델링 툴을 이용하여 작업할 때
						( 3D 맥스, 마야 등 )
						기준이 되는 좌표계..

					-	일반적으로 해당 모델을 기준으로
						원점이 세팅됨..

					-	모델마다 자신을 기준으로 하는
						로컬 좌표계를 가지고 있음..

					-	Dx는 왼손 좌표계를 사용..
						[ 참고 : https://blog.naver.com/happylamb/20019118408
								 왼손 좌표계.png ]

			
				-----------------
				-	월드 좌표계..
					[ 참고 : [2] World coord.png ]
				-----------------

					-	생성한 모델의 위치를
						가상의 공간에 설정..

					-	가상 공간의 원점을 기준으로
						위치라는 개념을 갖게 됨..


				-------------------
				-	카메라 좌표계..
					[ 참고 : [3] Camera coord - 1,2.png ]
				-------------------

					-	월드 좌표계로 변환된 좌표계를
						카메라를 기준으로 변환..

					-	카메라의 위치를 원점으로 치환하여
						모델들의 위치를 변환..

			
				----------
				-	컬링..
					( 참고 : [4] Culling.png )
				----------

					-	최종적으로 연출될 화면에서
						카메라에 그릴 필요가 없는 폴리곤을
						그리지 않는 것..

					-	종류와 기능..

						-	백페이스 컬링..

							-	폴리곤의 후면 제외..


						-	뷰 프러스텀 컬링..

							-	카메라의 시야범위( 뷰 프러스텀 )에서
								벗어난 모델들 제외..


						-	오클루젼 컬링..

							-	다른 모델들에게 가려져서
								보이지 않는 모델들 제외..



				---------------
				-	조명 연산..
					[ 참고 : [5] Light Operation.png ]
				---------------

					-	현실 세계의 빛을
						가상의 공간에 연출..

					-	정반사광, 난반사광,
						환경광 등이 있음..



				------------
				-	클리핑..
					[ 참고 : [6] Clipping.png ]
				------------

					-	화면의 해상도에서 벗어난 부분을
						그리지 않음..


				----------
				-	투영..
					[ 참고 : [7] Projection.png ]
				----------

					-	3D 물체를 2D 평면인 모니터 화면에
						표현하기 위하여 3D 모델 좌표를
						2D 평면 좌표로 변환하는 것..


				------------
				-	뷰포트..
					[ 참고 : [8] ViewPort.png ]
				------------

					-	윈도우 창 또는 전체 화면의
						직사각형 영역에 이미지를
						연출하는 것..


				-------------------
				-	래스터 라이즈..
					[ 참고 : [9] Rasterize.png ]
				-------------------

					-	스크린 좌표로 버텍스들을 변환하면
						폴리곤 정보를 가지게 되는데
						각각의 폴리곤을 출력하는데 필요한
						픽셀 컬러를 계산하는 과정..

					-	폴리곤을 픽셀로 변환하는 과정..

					-	그래픽 카드에서 담당..


		---------------
		7.	깊이 버퍼..
			( Z 버퍼 )
			[ 참고 : https://ko.wikipedia.org/wiki/Z_%EB%B2%84%ED%8D%BC%EB%A7%81
					 https://blog.naver.com/hblee4119/221940188597
					 깊이 버퍼.png
					 깊이 버퍼 작동원리.png ]
		---------------

			-	화면에 그려질 각각의 픽셀에 대한
				깊이 값을 보관하는 버퍼..

				-	깊이 값..

					-	카메라가 설정된 지점으로 부터
						카메라가 바라보는 방향으로의
						일종의 거리값..

					-	보통은 Z축 거리..


			-	랜더링 파이프 라인에 의해서
				3차원 공간을 2차원 모니터 상에 출력..

				-	월드 -> 카메라 -> 투영 변환의
					과정을 거치게 되는데
					카메라 -> 투영 변환 까지 거치게 되면
					3차원 공간상의 모든 정점은
					( -1, -1, 0 ) ~ ( 1, 1, 1 ) 사이의
					공간에 위치하게 됨..

				-	이때의 Z좌표 값을 Z 버퍼라고 함..

				-	0에 가까울수록 카메라에 근접하고
					1에 가까울수록 카메라에서 먼 것이라고 간주..

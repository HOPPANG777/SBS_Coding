/*
	------------------
	2.	클래스와 객체..
	------------------

		--------------
		-	용어 정리..
		--------------

			-----------
			1)	캡슐화..
			-----------

				-	어떤 사물을 [ 데이터적 측면 ]과
					[ 기능적 측면 ]을 통해 정의 하는 것..


					예)	코끼리..

						-	기능적 측면..
							-	코로 목욕..
							-	코로 물건을 집음..
						
						-	데이터적 측면..
							-	발 4개..
							-	긴 코..
							-	몸무게 1톤..

			------------
			2)	클래스..
			------------

				-	캡슐화 된 사물을 가지고
					자료형을 정의..

					ㄴ	데이터 + 기능적 측면..


				-	선언..
				
					-	멤버 변수와 멤버 함수의
						선언들로 구성된 부분..


				-	정의..

					-	멤버함수의 정의로
						구성된 부분..

			-------------------
			3)	객체, 인스턴스..
			-------------------

				-	클래스를 이용해
					정의된 변수..

*/
//=================================================

	[ Example ] 참고..

	----------------
	3.1	클래스 선언..
	----------------

		class   클래스 명

	--------------------------
	3.2	클래스 멤버의 접근제어..

		==========================================
		접근 제어자	|	클래스 외부	|	자식 클래스
		==========================================
		public		|		O		|		O
		protected	|		X		|		O
		private		|		X		|		X
		==========================================
			
		
		-	디폴트 접근제어..

			ㄴ	접근 제어자가 없는 경우..

			-	클래스..
				ㄴ	private

			-	구조체..
				ㄴ	public


		-	접근 범위..
			-	public	>	protected	>	private

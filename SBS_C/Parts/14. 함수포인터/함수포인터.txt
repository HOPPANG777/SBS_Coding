14.	함수 포인터
====================================================================================

	----------
	1.	개요..
	----------

		1.	변수 뿐만이 아니라
			프로그래머가 구현하는 모든 함수도
			바이너리 형태로 메모리 공간에
			저장되어서 호출 시 실행됨..

			참고 :	[ 10. 함수와 변수 ]
					> [ 3. 재귀함수 ]


		2.	함수 포인터..

			ㄴ	메모리상에 저장된 함수의 주소 값을
				저장하는 포인터 변수..


		3.	배열의 이름..

			==	배열의 시작 주소..


			함수 이름..

			==	함수가 저장된 메모리 공간의
				주소 값..

			배열과 마찬가지로 함수의 이름도
			[ 상수형 포인터 ]..



	----------
	2.	선언..
	----------

		1.	함수 포인터의 포인터 타입 결정..

			-	어떤 함수의 함수 포인터 타입..
			
				ㄴ	[ 반환형 ]과 [ 매개변수 리스트 ]로 결정됨..



			예 1)

				int TestFunc( int num )	{ ..... }

				-	TestFunc 분석

					-	반환형..
						ㄴ	int..
	
					-	매개변수..
						ㄴ	int num..

	
					->	TestFunc의 포인터 타입..
						
						ㄴ	반환형이 int 형,
							매개변수는 int형 데이터
							한 개로 구성된 포인터 타입..


			예 2)
		
				double TestFunc2( int num1, double num2 ) { ...... }

				ㄴ	TestFunc2의 포인터 타입은 ?


			-	
				1)	int BirthDay( int Year, int Month );

				2)	char* GetGrade( int score );

				3)	int Class( int Grade, int ClassNum );

				4)	char* GetQuest( int idx );

				ㄴ	위 함수들 중 포인터 타입이
					동일한 것은 ?
			
			

			
		2.	함수 포인터 변수 선언..

			-	[ 반환형 정보 ]와
				[ 매개변수 선언의 정보 ]가
				표현되어야 함..


			예) 반환 형이 int 형,
				매개 변수는 int형 변수 한 개로
				구성된 함수의 함수포인터 변수는..

				1)	포인터 변수 이름 선언..
					-	    (*ptrFunc)

				2)	"반환형 int" 적용..
					-	int (*ptrFunc)

				3)	"매개변수는 int형 변수 한개" 적용
					-	int (*ptrFunc)(int)


			-	int Func( int num1, int num2 ) { ..... } 의 함수 포인터 변수

				-	int (*ptrFunc)(int, int)

				-	할당..
					-	ptrFunc = Func;

				-	함수 포인터 사용..

					-	int res = ptrFunc(3, 4);
						
						==	int res = Func(3, 4);
		

	----------
	3.	용도..
	----------

		1>	개발자에게는 인터페이스만
			제공하고 알고리즘은
			상황에 따라 선택 해야하는 경우..


		2>	콜백 함수로 사용..

			ㄴ	함수의 호출 실행 시점을
				프로그래머가 아닌
				시스템에서 결정하는 함수.

				예) 오후 5시에 미팅이 있는 경우..

					매시간 마다 시간체크  vs  5시에 알람 설정..

	----------------------
	1.	자료형의 종류와
		데이터 표현 범위..
	----------------------
	
		----------
		-	정의..
		----------

			int a = 10;

			->	[ 4바이트 ] 크기의
				[ 정수형 ] 데이터 [ a ]를
				선언하여 [ 10 ]이란 값을
				저장..

			->	int..
				-	4바이트 크기의
					정수형 데이터..


			자료형..

			-	데이터를 표현하는 방식..


		----------------
		-	기본 자료형..
		----------------

			================================================================================
					|	자료형			|	크기	 			|	값의 표현 범위
					|					|( 1byte = 8 bit )	|
			================================================================================
			정수형	|	char			|	1byte			|	-128 ~ 127
					------------------------------------------------------------------------
					|	short			|	2byte			|	-32,768 ~ 32767
					------------------------------------------------------------------------
					|	int				|	4byte			|	-2,147,483,648
					|					|					|	 ~ 2,147,483,647
					------------------------------------------------------------------------
					|	long			|	4byte			|	-2,147,483,648
					|					|					|	 ~ 2,147,483,647
					------------------------------------------------------------------------
					|	long long		|	8byte			|	-9,223,372,036,854,775,808
					|					|					|	 ~ 9,223,372,036,854,775,807
			================================================================================
			실수형	|	float			|	4byte			|	3.4e-38 ~ 3.4e38
					------------------------------------------------------------------------
					|	double			|	8byte			|	1.7e-308 ~ 1.7e308
					------------------------------------------------------------------------
					|	double double	|	8byte or 이상	|	double 이상의 표현 범위..
			================================================================================


			*	long / int는
				크기와 표현 범위가 같다!!

				ㄴ	https://humn.tistory.com/9

				ㄴ	C/C++ 표준안은 정수 타입의 크기를
					정확하게 명시하고 있지 않음..

					ㄴ	다만 다음과 같은 최소한의 규정을
						가지고 있음..

						1.	short int의 크기는
							적어도 2바이트 보다
							커야 함..

						2.	int의 크기는 적어도
							short int의
							크기보다 커야 함..

						3.	long int의 크기는 적어도
							4 바이트보다 커야 하고
							int의 크기보다 커야 함..



		-------------------
		-	다양한 자료형을
			제공하는 이유..
		-------------------
		
			1)	데이터의 표현 방식이 다르므로
				최소 둘 이상의 자료형 필요..

				-	정수 / 실수..


			2)	메모리 공간의 적절한
				사용을 위해..

				예)
					정수 데이터를 5000개를
					처리하고 싶을때..

					short 를 이용..
					->	5000 * 2byte = 10,000 byte 소모..
					
					int 를 이용..
					->	5000 * 4byte = 20,000 byte 소모..




		-------------------------
		-	sizeof 연산자를 이용한
			자료형의 크기 확인..
		-------------------------
		
			-	sizeof..

				-	메모리 공간에 소모되는
					메모리 크기를
					바이트 단위로 반환..
				
				-	함수가 아니라 연산자임!!

			( "SizeOfOperator > 1.	sizeof 연산자." 참고 )




	------------------
	2.	자료형의 선택..
	------------------

		-----------------------
		-	정수 자료형의 선택..
		-----------------------

			-	일반적으로 short의 범위를
				넘어서는 범위의 값은
				int형을 사용..
	
				-	일반적으로 cpu가 처리하기에
					가장 적합한 크기의 정수 자료형을
					int로 정의..

					-	int 형의 연산 속도가
						다른 자료형의 연산속도에 비해
						동일하거나 빠름..

					-	short 형이나 char형 자료형을 연산할때
						int 형으로 형변환하여 연산이 진행 됨..

						->	연산을 위한 변수라면
							[ int ]형으로 선언하는 것이 좋음..

						->	데이터의 양이 많아
							속도보다 크기를 줄이는 것이
							더 중요하다면 
							[ byte ], [ char ], [ short ]등
							작은 데이터 타입으로 선언..
						
							예)	음성 또는 영상 데이터 등..

			

			( "SizeOfOperator > 2.	정수 자료형의 선택" 참고 )

			

		-----------------------
		-	실수 자료형의 선택..
		-----------------------


			-	실수형 데이터의 표현 범위는
				매우 넓다..

				-	값의 표현 범위 보다
					"정밀도"가 중요 요소..
		
				=============================================
					실수 자료형	|	소수점 이하	|	바이트 수
								|	정밀도		|
				=============================================
					float		|	6자리		|	4 바이트
					double		|	15자리		|	8 바이트
					long double	|	18자리		|	12 바이트
				=============================================



		---------------------------
		-	unsigned를 이용하여
			0 ~ 양의 정수(!) 표현..
		---------------------------

			====================================================================
					|	자료형			|	크기		|	값의 표현 범위
			====================================================================
					|	char			|			|	-128 ~ 127
					---------------------	1byte	----------------------------
					|	unsigned char	|			|	0 ~ 127 - (-128)
					------------------------------------------------------------
					|	short			|			|	-32,768 ~ 32767
					---------------------	2byte	----------------------------
			정수형	|	unsigned short	|			|	0 ~ 32767 - (-32,768)
					------------------------------------------------------------
					|	int				|			|	-2,147,483,648
					|					|			|	~ 2,147,483,647
					---------------------	4byte	----------------------------
					|	unsigned int	|			|	0 ~ 2,147,483,647
					|					|			|		- (-2,147,483,648 )
			====================================================================

				-	unsigned 	정수 자료형	변수명;

					예)	char ch = 'A';
						unsigned char ch2 = 'A';

				-	unsigned는
					MSB도 데이터의 크기를
					표현하는데 사용..

				-	값의 표현 범위가
					0 이상의 범위로
					2배가 됨..
			

							-128					0						127
							|-----------------------|-----------------------|
			char			1000 0000			0000 0000				0111 1111


				   			0						128						255
							|-----------------------|-----------------------|
			unsigned char	0000 0000			1000 0000				1111 1111

	3.	문자의 표현 방식과
		자료형..
	----------------------

		--------------------------
		-	컴퓨터는 숫자를 이용해서
			자료를 인식하고 표현..
		--------------------------

				표현해야 함..

			-	특정 숫자를 특정 문자로
				인식하도록 약속..

				-	예)	문자 A - 숫자 65
						문자 B - 숫자 66
						....

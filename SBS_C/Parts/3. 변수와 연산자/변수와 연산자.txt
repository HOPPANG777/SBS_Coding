			-	값을 저장할 수 있는

		-----------------
		-	변수의 선언..
		-----------------	

			----------
			-	형식..
			----------


				ㄴ	변수 타입	변수명;

					ex)	int	score;

							int..

							ㄴ	변수 타입..

							ㄴ	정수형 데이터의 저장이 가능한
								메모리 공간을 만들기 위한
								틀( Frame ) 또는 설계도..


							score..

							ㄴ	변수명..

							ㄴ	메모리 공간의 이름은
								score..


			( 소스 참고 : "1. 변수를 이용한 데이터 저장" )




		--------------
		-	변수의 선언
			및 초기화..
		--------------

			-	초기화..

				ㄴ	선언된 변수에
					값을 세팅하는 것..
					
				ex) 	int score;			//	선언..

						score = 90;			//	정의..

						int score = 100;	//	초기화..
												ㄴ	선언와 정의를
													동시에 진행..

		
			-	둘 이상의 변수를 동시에
				선언 및 초기화도 가능..
			
				ex)	int scoreEng, scoreKor;

					int scoreEng = 100, scoreKor = 100;

			( 소스 참고 : "2.	변수의 선언 및 초기화" )



		---------------
		-	변수 선언 시
			주의 사항..
		---------------

			-	변수의 이름을 구성하는
				주요 성분..

				ㄴ	알파벳..
				ㄴ	숫자..
				ㄴ	언더바(_) 등..


			-	C/C++ 언어는
				대/소문자를 구분..
				
					예)	int score; != int Score;


			-	변수 작명 시 숫자로
				시작하는 단어는 불가..
			
			-	키워드는 변수의 이름으로
				사용 불가...

				ㄴ	함수명, 자료형 등..

			-	변수명 사이에 공백 불가..

					예)	int max Value;		-	( X )
						->	int maxValue;	-	( O )


			-	변수명 중복 생성
				불가..

					예)
						int score = 100;

						......

						int score = 30;	-	(X)

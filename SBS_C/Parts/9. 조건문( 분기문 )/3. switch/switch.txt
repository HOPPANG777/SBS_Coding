========================================================================	
	switch
========================================================================

	------------
	1.	switch..
	------------

		1.	if ~ else 문과 유사..


		2.	형식..

			switch( 정수형 변수 )	//	char도 정수..
			{
				case 1:
					....
					break;

				case 2:
					....
					break;

				default :
					....
					break;
			}


			---------------
			-	case 정수 :
			---------------

				-	switch의 정수형 변수에
					해당하는 값이라면
					case 문 처리..

				-	case문의 끝에
					[ : ] 으로 마무리..
		


			-----------
			-	break..
			-----------

				-	반복문 뿐만 아니라
					switch문을 탈출하는
					용도로도 사용..

				-	break문이 없다면
					해당 case문 이하에 나열된
					case문을 모두 실행하되 
					다음 break문을 만나는 시점에서
					switch를 탈출..



			-------------
			-	default..
			-------------

				-	case 문에 정의 된 조건에
					해당하는 값이 아닌
					모든 경우에 실행..
			
				-	if ~ else의 else와 유사하며
					불필요한 경우 생략 가능..


			( "switch"참고 )

1]	헤더 파일
=====================================================================
	
	1>	특징..
		
		-	*.h 라는 확장자를 가짐..
		-	전역변수, 함수의 선언이나
			구조체 타입을 선언함..
			-	용도별로 그룹화하여
				선언하면 관리하기에
				편리..
			-	main 파일의 크기가
				줄어듬..
		-	특정 헤더파일을
			include한 파일에다가
			헤더 파일에 기록된 내용들을
			포함하게 함..



	2>	목적..

		-	소스 관리의 편의성 증가..
			-	유지보수 용의..
			
		-	재사용..
			-	독립적으로 돌아가도록
				작성하여
				다른 프로젝트에서도
				활용 가능..


	3>	사용법..
		
		1)	#include <filename.h>
			-	컴파일러와 함께 제공되는
				헤더 파일을 포함..
			-	런타임 라이브러리의 헤더파일로써
				운영체제의 특정 위치에 존재함..

		2)	#include "filename.h"
			-	소스 파일이 있는 디렉토리에서
				헤더파일을 포함하도록 지시..
			-	개발자가 만든 헤더파일은
				이 방식을 이용..


	4>	표준 라이브러리 헤더 파일..
		
		#include <stdio.h>
		
		int main()
		{
			printf("hello world\n");
			return 0;
		}

		-	printf 라는 함수를
			따로 정의하지 않았지만 
			stdio.h라는 헤더파일에
			선언되어 있으므로 사용 가능..

		-	#include <stdio.h>
			-	stdio.h라는 헤더파일의
				모든 내용을 복사해오도록
				요청..
			-	헤더파일의 내용을
				현재 코드 파일에서
				사용 가능..
			-	헤더파일은
				일반적으로 선언만 포함..
				실제 정의는
				링크 단계에서 자동으로
				프로그램에 링크되는
				C 런타임 지원 라이브러리에서
				구현..
			-	stdio.h 파일이 존재하지 않는다면
				printf 와 관련된 모든 선언을
				각 파일의 맨 위로
				일일이 복사해야함..


=====================================================================
2]	헤더 파일 작성하기.
=====================================================================

	1>	개요..
		-	main함수 앞부분에서
			함수의 선언부를 기입( 전방선언 )하고
			함수의 구현부는
			main함수 뒷부분에 정의함..
			-	[ 10. 함수와 변수 > 1. 함수의 정의와 선언 ] 참고..
		-	모든 함수를
			이런식으로 전방 선언하는 것은
			번거로움..
		-	함수의 경우,
			전방선언은 *.h에,
			구현부는 *.c 파일에 구현..


	2>	헤더파일 구현..
		1)	헤더 가드..
			-	헤더 파일이 같은 파일에서
				두번 이상 포함( include )되지 않게 함.

		2)	헤더파일 몸체..
			-	헤더파일의 실제 선언부..

=======================================================================		
	배열을 이용한 문자열 변수의 표현
=======================================================================

	------------------
	1.	char형 배열의
		문자열 저장과
		널(null)문자..
	-----------------

		------------------------
		1.	문자와 문자열의 표현..
		------------------------

			-	문자..

				ㄴ	''를 사용..

				ㄴ	아스키 코드..

				ㄴ	한 개의 단어 표현..

					예)	'a', 'A', ' ', '\t', '\n' 등..
				


			-	문자열..

				ㄴ	""를 사용..

				ㄴ	주로 연속된 2개 이상의
					단어들을 표현..

					예)	"Hi", "Hello!!" 등.
						"a", "A"..


		-----------------------------
		2.	char형 배열의 문자열 저장과
			널(null)문자..
		-----------------------------

			-	char str[14] = "Good morning!";

				다음과 같이
				메모리 상에 저장..

				----------------------------------------------------------
				| G | o | o | d |   | m | o | r | n | i | n | g | ! | \0 |
				----------------------------------------------------------

			-	char str[ ] = "Good morning!";

				이 방식도 가능..

				-	이때 배열의 길이는
					14로 간주..

					ㄴ	'\0' 자동 포함..


			-	문자의 갯수는
				공백과 느낌표까지
				총 13개!!

				문자열의 끝에는
				'\0' 이라는 특수문자가
				자동으로 삽입 됨..

				ㄴ	실제 문자열의 길이는 
					'\0'를 포함하여 14..


			-	문자열의 저장을 목적으로
				char형 배열을 선언할 경우
				특수문자 '\0'이 저장될 공간까지
				고려해서 배열의 길이를 결정할 것..


			-	널문자..
				( null : 아무 가치없는 )

				ㄴ	문자열의 끝에
					자동으로 삽입되는
					문자 '\0'

			[ "CharArray"참고 ]

=======================================================================

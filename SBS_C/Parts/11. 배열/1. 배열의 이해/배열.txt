=======================================================================	
	배열의 이해와 선언 및 초기화
=======================================================================

	----------
	1.	배열..
	----------

		1.	정의..

			-	둘 이상의 같은 타입의
				변수를 모아 놓은 것..


		2.	필요성..

			예)	A 라는 10층 짜리 아파트의
				한 가구 당 가족수를
				관리하기 위한
				프로그램을 만들어야한다..

				각 층에는 네 가구씩 살고 있다고
				가정 했을때, 가족수를 관리할
				변수를 만든다면..

					int houseNum101, houseNum102, houseNum103, houseNum104;
					int houseNum201, houseNum202, houseNum203, houseNum204;
					int houseNum301, houseNum302, houseNum303, houseNum304;

					..............

					int houseNum1001, houseNum1002, houseNum1003, houseNum1004;
	
				이런식으로 선언해야 한다..
				
			-	배열의 목적..

				ㄴ	한 번에 여러 개의 변수를
					선언하여 관리하기 위해 사용..



		3.	형식..

			-	변수형	배열이름 [ 배열 길이 ]

				예)	int testArray[4];

					-	[ int ]타입의 변수 [ 4개 ]로 이뤄진
						[ 배열 ]이며 [ 이름 ]은
						[ testArray ]..

					-	메모리상의 구조..

						-------------------------------------------------------------------------------------------
						|----- int ------|----- int ------|----- int ------|----- int ------|    |    |    | . . . 
						|	 (4byte)	 |	  (4byte)	  |	   (4byte)	   |    (4byte)		| 1b | 1b | 1b | . . . 
						| testArray[ 0 ] | testArray[ 1 ] | testArray[ 2 ] | testArray[ 3 ] |    |    |    | . . . 
						-------------------------------------------------------------------------------------------
			
						-	int 형 변수 4개가
							연속적으로 나란히 선언..



			-	배열 길이는 상수로 설정..

				============================================
						시대		|	규격..
				============================================
					과거 C 표준..	|	반드시 상수로 지정..
				--------------------------------------------
					새로운 C 표준..	|	변수로 지정도 가능..
				============================================

				-	하지만 일부 컴파일러에선
					과거 제약 사항을 고수하는
					컴파일러도 존재..

					ㄴ	배열 길이는
						가급적 상수로 지정..

				
					과거)		int testArray[4];

								const int length = 5;
								int testArray[length];



					새 표준 )	int len = 4;
								int testArray[len];



		4.	배열의 접근..

			-	배열은 [] 연산자 사이에
				배열의 위치 정보를 명시..

			-	인덱스..
				ㄴ	[]에 들어가는 숫자..
				ㄴ	배열 요소의 순서를 의미..

			-	배열의 위치 정보인
				인덱스 값은 0부터 시작..

				ㄴ	첫번째 배열의 값
					ㄴ	testArray[ 0 ].

					마지막 요소
					ㄴ	testArray[ length - 1 ]
						
						ㄴ	length
							
							ㄴ	배열의 전체 길이..
			
			[ "Array"참고 ]

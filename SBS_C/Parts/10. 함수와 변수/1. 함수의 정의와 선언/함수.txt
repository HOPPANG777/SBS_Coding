	함수의 정의와 선언
================================================================
	
	----------
	1.	함수..
	----------

		----------
		0.	정의..
		----------

			ㄴ	function..
				-	기능..

			ㄴ	특정 작업을 수행하도록
				독립적으로 설계된 코드 그룹..

			ㄴ	기능을 구현하는 부분..



		------------
		1.	필요성..
		------------

			--------------------
			-	코드가 간결해짐..
			--------------------
			
				ㄴ	자주 사용하는 코드를
					함수로 만들면
					반복되는 부분에 함수 한줄만
					넣어주면 됨..

            
			------------------
			-	작업의 모듈화..
			------------------

				ㄴ	크고 복잡한 소스를
					기능별로 나누어 단순화..


			------------------
			-	코드의 재활용..
			------------------

				ㄴ	한번 만들어 놓은 함수는
					필요한 경우 다시 호출..

					예) printf, scanf 등..


			-------------------
			-	코드의 에러 발생
				해결..
			------------------

				ㄴ	문제 발생시
					원인추적이 용이..


			--------------
			-	기능 수정..
			--------------

				ㄴ	소스 코드의 변경이
					필요한 경우,
					변경 범위를 축소 및
					제한할 수 있음..




		----------------
		2.	함수의 형태..
		----------------

			
			반환 형태( 리턴 타입 )		함수이름	( 입력 형태 ( 매개변수 리스트 ) )
			{
				함수의 몸체
			}
			
			예)	int Plus( int a, int b ) 
				{
					return a + b;
				}

			**	[ 함수.PNG ] 참고


			----------------
			-	반환 형태..
				( 리턴 타입 )
			----------------

				-	결과물이 필요한 경우,
					함수의 실행 결과를
					함수를 호출한 부분에 반환..

				-	반환 값이 필요없는 경우 void..


			-----------------------
			-	입력 형태..
				( 매개 변수 리스트 )
			-----------------------

				-	함수의 기능 작업시
					외부에서 값을 받아야할
					필요가 있는 경우 명시..

				-	필요 없을 땐 void 또는
					명시해주지 않아도 됨..

	-------------------------
	0.	메모리 영역..
	-------------------------

		1)	코드 영역..( 텍스트 영역 )
			-	실행할 프로그램의
				코드가 저장되는 영역..
			-	CPU는 코드 영역에 저장된 명령을
				하나씩 가져가서 처리..
			-	컴파일 타임에 결정되고
				중간에 코드를 바꿀 수 없게
				읽기전용으로 지정됨..
			-	프로그램의 시작과 함께 할당되며
				프로그램이 종료되면 소멸..

		2)	데이터 영역..
			-	전역 변수와 정적(static) 변수가
				저장되는 영역..
			-	프로그램의 시작과 함께 할당되며
				프로그램이 종료되면 소멸..

		3)	스택 영역..
			-	프로그램이 자동으로 사용하는
				임시 메모리 영역..
			-	함수( 또는 코드 블록 )안에서 선언된
				지역변수, 매개변수, 리턴값,
				돌아올 주소값 등이 저장..
			-	메모리 할당..
				-	함수 호출시..
				-	코드 블록 시작시..
				메모리 제거..
				-	함수 종료시..
				-	코드 블록 종료시..
			-	컴파일 타임에
				크기가 결정되기 때문에
				무한히 할당 할 수 없음..
				-	스택 영역의 범위를 초과하면
					스택 오버플로우 발생..
					-	재귀함수가 너무 깊게
						호출하는 경우..
					-	함수가 지역변수를
						너무 많이 가지고 있는 경우..
					


		4)	힙 영역..
			-	프로그래머가 직접
				공간을 할당, 해제하는
				메모리 공간..
			-	다른 영역들과는 달리
				런타임에 생성, 소멸됨..
			-	주로 사용할 데이터 배열의
				크기가 확실치 않고
				변동이 생길수 있는 경우
				활용..
			-	메모리 할당후
				반드시 정리를 해야하며
				그렇지 않으면
				메모리가 할당된 상태로
				유지가되어
				다른 프로그램들이
				사용할 공간이 
				상대적으로 줄어듬..
				-	메모리 릭..( Memory Leak )
			-	스택에 비해
				할당 가능한 메모리 공간이
				많지만 포인터로 접근하기 때문에
				상대적으로 데이터를
				읽고 쓰는게 느림..
		
	-------------------------
	1.	전역변수와 지역변수
	-------------------------

		1.	차이

			-	변수의 생명
				-	메모리상에
					존재하는 기간..
	
			-	변수의 접근 범위
				-	변수가 참조 가능한
					범위..

		

	-------------------------
	2.	지역 변수
	-------------------------

		1.	정의.

			-	지역..
				-	중괄호에 의해
					형성되는 영역..

				-	{
						..코드 블록, 지역.			
					}

			-	중괄호 내에
				선언되는 변수는
				모두 지역 변수..
				-	클래스( c++ ), 구조체 제외
					-	멤버변수..

			-	선언 또는
				초기화 된 지역에서만
				접근 가능..
	
				-	선언된 지역이 다르면
					이름이 같아도
					문제없음..

				-	{
						int A = 100;			-	(1)

						{
							int A = 10;		-	(2)	문제가 되지 않지만
													외부에 선언된
													동일한 이름의
													변수 (1)A 를 가린다.

													(2) 이하에서 사용되는
													A라는 이름의 변수는
													(2) A를 가리킨다.
							............

							A += 10;

						}

						............
			
					}

			-	프로그램의 흐름이
				해당 지역을 벗어나면
				자동으로 소멸..

				-	자동 변수라고도 함.

				-	{
						int A = 100;

						{
							int B = 10;

							int C = A + B;

							............

						}	->	B, C 소멸..

						............
			
					}	->	A 소멸..

			( "Local Variable" 참고 )

=========================================================	
	do ~ while
=========================================================

	--------------------
	1.	[ do ~ while ]의
		구성..
	--------------------

		------------
		1.	필요성..
		------------

			-	반복 영역이 최소한
				한 번은 실행되어야 하는
				구조..


		----------
		2.	형식..
		----------

			do
			{
				반복 구간
				
				....

				반복 조건이 무너지게 하는 연산
				또는 카운팅 연산..
			}
			while( 반복 조건 );


		---------------------
		3.	[ while ]
			vs [ do ~ while ]
		---------------------

			-	반복 조건의 검사 위치가
				다름..

				-	반복 영역이 최소
					1회 이상 실행..

					ㄴ	사실 [ do ~ while ]과
						[ while ]은 서로 대체 가능..

						-	일반적으로 while문이
							코드 작성이나 가독성이
							더 높으므로 더 많이 사용..


		---------------------
		4.	[ do ~ while ]을
			더 선호하는 상황..
		---------------------

			( "do ~ while" 참고 )
